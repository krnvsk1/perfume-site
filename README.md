# Парфюмерная Комната

Витрина распива духов: каталог с поиском и фильтрами, корзина на несколько ароматов, вход покупателя по номеру телефона с историей заказов, админка и уведомления о заказах в Telegram.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Витрина: каталог, карточка аромата, корзина, вход по телефону, «Мои заказы» |
| `admin.html` | Админка: ароматы, остатки, фото, заказы и их статусы. На витрине ссылки на неё нет |
| `store.js` | Работа с данными (демо или Supabase) |
| `config.js` | Подключение к Supabase, контакты и адреса магазина |
| `styles.css` | Оформление |
| `data/price.txt` | Прайс распива, перенесённый с Taplink |
| `data/catalog.js` | Каталог для демо-режима, собирается из прайса |
| `images/` | Фото флаконов |
| `tools/build_catalog.py` | Пересобирает `catalog.js` и `seed.sql` после правки прайса или фото |
| `supabase/schema.sql` | Таблицы, правила доступа и оформление заказа |
| `supabase/seed.sql` | Загрузка прайса в базу |
| `supabase/functions/notify/index.ts` | Отправка заказов в Telegram |

## Запуск локально

```bash
cd perfume-site
python3 -m http.server 8000
```

Витрина: http://localhost:8000, админка: http://localhost:8000/admin.html.

Пока в `config.js` пустые поля, сайт работает в демо-режиме: всё хранится в браузере, SMS не отправляются (код для входа всегда `1234`), а в админку пускает без пароля.

## Как покупает клиент

1. Нажимает на аромат, карточка раскрывается: выбирает объём (от 2 мл) или целый флакон и добавляет в корзину.
2. В корзине можно добавить ещё ароматы, поменять объём или убрать позицию.
3. При оформлении входит по номеру телефона: получает код в SMS и вводит его. Имя запоминается для следующих заказов.
4. Заказ приходит тебе в Telegram, а у клиента появляется в «Мои заказы» со статусом.

Статусы заказа меняются в админке: «Принят», «Готов к выдаче», «Выдан», «Отменён». Клиент видит их у себя.

## Прайс, контакты и фото

Контакты, адреса и часы работы лежат в `config.js` в разделе `SHOP`. Прайс лежит в `data/price.txt`: одна строка на аромат, поля через `|`. После правки выполни `python3 tools/build_catalog.py`. Когда база подключена, ароматы удобнее менять в админке.

Фото кладутся в папку `images` с именем из бренда и названия латиницей через дефис, например `mancera-red-tobacco.webp`. Затем `python3 tools/build_catalog.py` сам привяжет их к ароматам. Лучше всего смотрятся вертикальные фото 600 × 800 без фона или на белом фоне.

## Подключение настоящей базы

1. Зарегистрируйся на https://supabase.com и создай проект.
2. SQL Editor → вставь содержимое `supabase/schema.sql` → Run. Затем так же выполни `supabase/seed.sql`, чтобы загрузить прайс.
3. Authentication → Users → Add user: создай себе почту и пароль для входа в админку.
4. Сделай этого пользователя администратором. В SQL Editor выполни, подставив свою почту:
   ```sql
   insert into admins select id from auth.users where email = 'твоя@почта.ru';
   ```
5. Authentication → Sign In / Providers: выключи вход по почте для новых пользователей (Email → «Allow new users to sign up»), а вход по телефону (Phone) включи, см. следующий раздел.
6. Project Settings → API: скопируй Project URL и anon public key в `config.js`.

Покупатели входят по телефону, но права администратора есть только у пользователей из таблицы `admins`. Без них никто не может менять ароматы и не видит чужие заказы, даже если найдёт адрес админки.

## Вход по SMS

Чтобы коды приходили на телефон, Supabase нужен SMS-сервис. SMS платные: каждая стоит денег у выбранного сервиса.

- **Встроенные провайдеры.** Authentication → Sign In / Providers → Phone: включи и выбери провайдера из списка (например Twilio), вставь его ключи. Перед выбором проверь, что провайдер доставляет SMS на российские номера.
- **Российский SMS-сервис.** Если нужен местный сервис (например SMS.ru или SMSC), его подключают через Send SMS Hook в разделе Authentication → Hooks: Supabase передаёт код в твою функцию, а она отправляет SMS через API сервиса. Эту функцию можно дописать отдельно.

Пока SMS не настроены, вход по телефону в рабочем режиме работать не будет.

## Уведомления в Telegram

1. В Telegram открой @BotFather → `/newbot` → получишь токен.
2. Напиши своему боту любое сообщение, затем узнай свой chat id у @userinfobot.
3. Supabase → Edge Functions → создай функцию `notify` с кодом из `supabase/functions/notify/index.ts`.
4. Edge Functions → Secrets: добавь `TG_TOKEN` и `TG_CHAT`.
5. Database → Webhooks → Create: таблица `orders`, событие Insert, тип Supabase Edge Function, функция `notify`.

В сообщении приходят номер заказа, все позиции с объёмами и ценами, итог, имя и телефон клиента.
